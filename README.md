# Calculadora de Juros Compostos 

Projeto desenvolvido para praticar HTML, CSS e JavaScript, criando uma calculadora de juros compostos com uma interface simples e intuitiva.

## 🚀 Funcionalidades

* Informar o valor inicial do investimento
* Definir a taxa de juros
* Escolher o período de aplicação
* Calcular o montante final e os juros obtidos

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

Praticar conceitos de desenvolvimento web, estilização com CSS e lógica de programação com JavaScript.
